## Product Intent

Run a complete advanced analytics workflow end-to-end through Yamori's dependency graph: multidimensional portfolio integration (Vegas/Suave) + spectral signal decomposition (FFT) + cycle detection. Demonstrate that the same M1 runtime serves five distinct domains with fundamentally different numerical methods (cash flow projection, signal processing, numerical pricing, matrix linear algebra, high-dimensional integration, spectral analysis). Produce deterministic, bit-identical results across all four target platforms. Validate that all five domains operate independently on the same graph. This is the final M8 epic — the proof that Yamori is a general financial computation runtime, not a single-domain tool.
