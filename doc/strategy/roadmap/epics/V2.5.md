# V2.5: Terminal Value, Equity Bridge, and Per-Share Value

**Labels:** `type/epic`, `type/enhancement`, `area/finance`
**GitHub Issue:** TBD

Computes discount factors via iterative multiplication (no `std.math.pow`), discounts FCFF to present value, calculates Gordon terminal value from year-11 FCFF, bridges operating asset value to equity value via debt/cash/non-operating assets, divides by shares outstanding, applies single FX translation. Terminal value share tracked as an audit metric.

## Product Intent

Deliver the terminal value and equity bridge computation: discount FCFF to present value using iterative multiplication, calculate Gordon terminal value from year-11 FCFF, bridge operating asset value to equity value via debt/cash/non-operating assets, divide by shares outstanding, and apply FX translation. Track terminal value share as an audit metric. The outcome is a complete per-share intrinsic value estimate — the final number in the M2 valuation loop.

## Users And Jobs

- [Investment analyst]: View the complete terminal value and equity bridge computation — operating asset value, terminal value, debt/cash adjustments, shares outstanding, FX translation, and final per-share intrinsic value.
- [Compliance reviewer]: Verify that discount factors use iterative multiplication (not `std.math.pow`), that the terminal value share is within reasonable bounds, and that the equity bridge accounts for all non-operating assets and liabilities.
- [Engineer]: Add new equity bridge formula nodes to the dependency graph without modifying existing discount or terminal value logic.
- [Tickoni tile]: Consume `computePerShareValue(fcff_schedule, bridge_data, policy)` as a callable pivot that returns per-share intrinsic value with full audit trail.

## Success Metrics

- Discount factors: computed via iterative multiplication (no `std.math.pow`) for determinism.
- FCFF present value: sum of discounted ten-year FCFF.
- Gordon terminal value: year-11 FCFF / (WACC − terminal growth rate).
- Equity bridge: operating asset value + terminal value − debt + cash ± non-operating assets.
- Shares outstanding: from the subject-company's capital structure.
- FX translation: single FX rate applied to convert to reporting currency.
- Terminal value share tracked as an audit metric: (terminal value / operating asset value) — flagged if > 75%.
- All computations expressed as formula nodes on the dependency graph.

- Expected result: A complete per-share intrinsic value with the full equity bridge displayed — operating asset value, terminal value, debt/cash adjustments, shares outstanding, FX translation, and final per-share value.

### How Many Stories?

Seven stories: discount factors (S1), FCFF present value (S2), Gordon terminal value (S3), equity bridge (S4), shares outstanding (S5), FX translation (S6), and terminal value share audit (S7). The scope is the complete terminal value and equity bridge — the final computation in the M2 valuation loop.

### Decomposition Rules

1. **Independent delivery**: Each story compiles and produces a verifiable terminal value component.
2. **One capability per story**: S1 = discount factors; S2 = FCFF PV; S3 = Gordon terminal; S4 = equity bridge; S5 = shares; S6 = FX; S7 = audit metric.
3. **Split by capability lifecycle**: S1–S3 compute the discounted cash flows; S4–S6 bridge to equity value; S7 adds the audit layer.
4. **Closure story**: S7 returns the complete per-share value with audit metric — the evidence layer that closes the M2 valuation loop.

### Bad Splits (Avoid)

- "FCFF present value" + "Gordon terminal value" as separate epics. They are the same discounted cash flow framework.
- "Equity bridge" + "Shares outstanding" as two stories. They are part of the same per-share computation.
