Runs a complete technical analysis pipeline — price series → moving averages → oscillators → volatility indicators → volume indicators — through the same dependency graph, backend router, and deterministic execution policy that powers intrinsic valuation. Proves the M1 runtime serves both domains with no cross-domain interference, and results are bit-identical across all four target platforms.

## Product Intent

Run a complete technical analysis workflow end-to-end through Yamori's dependency graph, demonstrating that the same M1 runtime serves both Damodaran valuation (M1–M5) and technical analysis (V6.1–V6.5). Validate deterministic, bit-identical results across Linux x86, Linux ARM, macOS ARM, and Windows x86. Confirm that Damodaran and TA-Lib node sets operate independently on the same graph.

## Users And Jobs

- [Investment analyst]: Run a complete technical analysis pipeline on a single dataset and see all indicators computed through the same interface used for valuation.
- [Engineer]: Validate that the technical analysis pipeline produces deterministic, bit-identical results across all four target platforms.
- [Compliance reviewer]: Verify that no cross-domain interference occurs between Damodaran valuation nodes and TA-Lib indicator nodes on the same graph.

## Success Metrics

- Complete TA pipeline runs end-to-end: price → MAs → oscillators → volatility → volume indicators.
- Pipeline uses the same backend router and deterministic execution policy as the Damodaran engine.
- Bit-identical results across Linux x86, Linux ARM, macOS ARM, and Windows x86.
- No cross-domain interference: Damodaran and TA-Lib nodes share the graph but operate independently.
- Same input data and TA-Lib version produce identical outputs on all platforms.

## Demo Moment

- Command or flow: `yamori analysis run --domain=technical --input=price_series`
- Expected result: Complete technical analysis output — moving averages, RSI, Bollinger Bands, OBV, and candlestick patterns — all computed deterministically, bit-identical across platforms, with no interference from Damodaran valuation nodes.
