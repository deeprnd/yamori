
# V9.2: Equity Option Pricing

V9.2 delivers deterministic pricing of equity options — the most traded derivative class in the world. By implementing European options (call/put) via Black-Scholes-Merton and American options via binomial trees (CRR, Bjerksund-Stensland) from QuantLib, it provides fair value and full Greeks (Delta, Gamma, Vega, Theta, Rho) for every major option type. Deterministic execution policy pins the algorithm (closed-form vs. tree), volatility model, and grid resolution, so results are bit-identical across all four target platforms. This is the first pricing epic built on V9.1's registry — the proof that QuantLib engines produce actionable outputs through Yamori's dependency graph.

## Product Intent

Deliver European and American equity option pricing through Yamori's unified backend. European options (call/put) priced via Black-Scholes-Merton closed-form solution; American options priced via binomial trees (CRR, Bjerksund-Stensland). Each option type accepts underlying price, strike, time-to-maturity, volatility, dividend yield, and risk-free rate, producing fair value and full Greeks (Delta, Gamma, Vega, Theta, Rho). Deterministic execution policy pins the algorithm choice, volatility model, and grid resolution — producing bit-identical results across all four target platforms. This is the first practical derivatives capability built on V9.1's registry infrastructure.

## Users And Jobs

- [Options trader]: Price European call/put options via Black-Scholes-Merton and American options via binomial trees (CRR or Bjerksund-Stensland), receiving fair value and full Greeks through Yamori's dependency graph.
- [Risk manager]: Compute option Greeks (Delta, Gamma, Vega, Theta, Rho) for a portfolio of equity options — deterministic, auditable, reproducible with pinned parameters.
- [Quantitative analyst]: Compare pricing across algorithms (closed-form vs. tree) for the same inputs to validate convergence and understand model risk.
- [Tickoni tile]: Consume `priceOption(type, underlying, strike, maturity, volatility, dividendYield, riskFreeRate)` as a callable pivot that returns fair value and Greeks through shared memory.
