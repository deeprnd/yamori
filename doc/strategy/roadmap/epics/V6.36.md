
# V6.2: Moving Average Indicators

Implements simple, exponential, weighted, double/triple exponential, Kaufman adaptive, MAMA, and T3 moving averages from TA-Lib. Each moving average accepts a price series and period parameter and produces a filtered series. These are the substrate for Bollinger Bands, MACD, and all oscillators that follow.

## Product Intent

Implement all major moving average types from TA-Lib as formula nodes on the dependency graph. Each moving average accepts a price series and period parameter, producing a deterministic filtered series. Moving averages serve as building blocks for higher-level indicators in subsequent epics.

## Users And Jobs

- [Investment analyst]: Apply multiple moving average types to the same price series and compare their smoothing characteristics.
- [Engineer]: Validate that each moving average type produces deterministic, bit-identical outputs across all target platforms.
- [Compliance reviewer]: Verify that period parameters are validated and that the TA-Lib implementation is pinned.

## Success Metrics

- SMA, EMA, WMA, DEMA, TEMA, KAMA, MAMA, T3 moving averages all implemented from TA-Lib.
- Each moving average is a formula node accepting price series + period.
- Deterministic execution policy pins the TA-Lib implementation.
- Bit-identical outputs across Linux x86, Linux ARM, macOS ARM, and Windows x86.
- Moving averages produce correct filtered series for standard test inputs.

## Demo Moment
