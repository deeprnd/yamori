V8.2 delivers Monte Carlo portfolio simulation through Cuba's Vegas and Suave integration engines. By integrating over high-dimensional probability spaces — correlated asset returns, multi-factor risk scenarios, path-dependent payoffs — it produces portfolio value distributions with statistical error bounds and convergence diagnostics. This is the first M8 epic that produces actual portfolio analytics: high-dimensional integration that is intractable with deterministic quadrature.

## Product Intent

Deliver Monte Carlo portfolio simulation via Vegas and Suave multidimensional integration. Integrate over high-dimensional probability spaces — correlated asset returns, multi-factor risk scenarios, path-dependent payoff integration — to produce portfolio value distributions. Vegas provides variance reduction via stratified sampling and importance sampling; Suave provides adaptive stratified sampling with automatic dimension reduction. Deterministic execution policy pins the RNG seed, random stream generator, sample count, and stratification strategy.

## Users And Jobs

- [Portfolio manager]: Estimate portfolio value distributions under correlated asset returns, with convergence diagnostics to assess simulation reliability.
- [Risk analyst]: Run multi-factor Monte Carlo scenarios to quantify tail risk, using Vegas for speed and Suave for dimension reduction on high-asset portfolios.
- [Quantitative analyst]: Compare stratified sampling (Vegas) vs. adaptive sampling (Suave) on the same portfolio to validate convergence behavior.
- [Yamori tile]: Consume `monteCarlo(portfolio, scenarios)` as a callable pivot that returns integral estimates, statistical errors, and convergence diagnostics.
