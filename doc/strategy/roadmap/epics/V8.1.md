V8.1 registers Cuba (Vegas, Suave, Divonne, Cuhre) and FFTW as backends in Yamori's unified backend router. Each integration method becomes a named formula node on the dependency graph, enabling high-dimensional integration and spectral analysis through the same deterministic infrastructure that serves valuation, technical analysis, and derivatives. This is the foundation for all subsequent M8 epics.

## Product Intent

Deliver the Cuba and FFTW backend registration that exposes multidimensional integration and spectral transform capabilities as named formula nodes on Yamori's dependency graph. The backend router (M1 Epic V1.2) isolates these numerical kernels from the graph logic; the combined registry maps Yamori operation identifiers to Cuba integration engines and FFTW transform types; deterministic execution policy pins all algorithmic parameters. This is the foundation for all subsequent M8 epics.

## Users And Jobs

- [Quantitative analyst]: Run high-dimensional Monte Carlo integration and FFT spectral analysis through the same dependency graph used for valuation and portfolio analytics.
- [Engineer]: Register new numerical integration and transform methods as named formula nodes without modifying the graph infrastructure.
- [Tickoni tile]: Consume `integrate()` and `transform()` as callable pivots that return deterministic numerical results.
