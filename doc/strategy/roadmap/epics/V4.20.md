
# V4.20: Monte Carlo Demo

**Labels:** `type/epic`, `type/enhancement`, `area/finance`
**GitHub Issue:** #21

V4.17-V4.19 build the Monte Carlo components individually. V4.20 runs the complete CSV → deterministic DCF → Monte Carlo distribution flow in one executable pipeline. It assembles the complete stack: Arrow CSV, Arrow Compute, GSL Statistics/Interpolation/Roots/RNG/Distributions. It proves that enabling simulation does not change the deterministic base valuation. It emits base value, mean, median, percentiles, dispersion, and valuation range. The outcome is a single end-to-end flow that proves all M4 Monte Carlo components work together — the CSV lands, the DCF runs deterministically, the Monte Carlo distribution forms, and the summary emerges, all in one reproducible pipeline.

## Product Intent

Deliver the Monte Carlo demo flow: run CSV → deterministic DCF → Monte Carlo distribution in one executable pipeline, assemble the complete stack (Arrow CSV, Arrow Compute, GSL Statistics/Interpolation/Roots/RNG/Distributions), prove that enabling simulation does not change the deterministic base valuation, and emit base value, mean, median, percentiles, dispersion, and valuation range. The outcome is a single end-to-end flow that proves all M4 Monte Carlo components work together in a reproducible pipeline.

### Decomposition Rules

1. **Independent delivery**: Each story produces verifiable pipeline output.
2. **One capability per story**: S1 = stack assembly; S2 = base preservation; S3 = output; S4 = reproducibility.
3. **Split by capability lifecycle**: S1 assembles the stack; S2 verifies the base; S3 emits output; S4 proves reproducibility.
4. **Closure story**: S4 returns the complete pipeline output with reproducibility proof.
