# V4.20: Valuation Spread Visualization

**Labels:** `type/epic`, `type/feature`, `area/investing`
**GitHub Issue:** TBD

A peer-set valuation table with discount/premium metrics is not enough — the analyst needs to see the valuation spread visually. V4.20 generates structured output showing valuation spreads: which companies trade at discount/premium to intrinsic value, which have the widest/narrowest spreads, and how the peer distribution looks. Outputs are machine-readable (JSON tables) for downstream consumption by Tickoni tiles or external consumers. The outcome is a machine-readable visualization of the peer-set valuation landscape — not a chart (that's V5.26 UI), but a structured data output that encodes the spread in a way that any downstream consumer can render.

## Product Intent

Deliver the valuation spread visualization engine: generate structured output (JSON tables) showing which companies trade at discount/premium to intrinsic value, which have the widest/narrowest spreads, and the peer distribution shape. Outputs are machine-readable for downstream consumption by Tickoni tiles or external consumers. The outcome is a structured representation of the valuation spread that any downstream system can render or analyze.

## Users And Jobs

- [Investment analyst]: See a structured spread output showing which companies are discounted, which are premium, and which have the widest/narrowest spreads — in a format any downstream system can render.
- [Compliance reviewer]: Verify that the spread calculations use peer medians (not means), that outliers are flagged, and that the JSON output is deterministic and machine-readable.
- [Engineer]: Extend the spread output by adding new visualization formats (CSV, Excel, ASCII chart) as policy-configurable options without modifying the core spread calculation.
- [Tickoni tile]: Consume `valuationSpread(peer_set_results)` as a callable pivot that returns a structured JSON table of spread metrics.

## Success Metrics

- Structured spread output: discount/premium to intrinsic value for every company.
- Widest/narrowest spread identification: flagged in the output.
- Peer distribution shape: encoded in structured output.
- Machine-readable: JSON tables for downstream consumption.
- Deterministic: same peer set produces identical spread output across runs.
- Every spread metric carries the full M1-M3 audit trail.

## Demo Moment

- Command or flow: `tickoni batch run --peers <peer_set_file> --spread --format json`
- Expected result: A JSON table showing discount/premium to intrinsic value, spread rankings, and peer distribution shape.

### How Many Stories?

Three stories: spread calculation (S1), rankings + distribution (S2), and JSON output + audit (S3). The scope is output formatting — narrow but essential for downstream consumption.

### Decomposition Rules

1. **Independent delivery**: Each story produces verifiable spread output.
2. **One capability per story**: S1 = spread calculation; S2 = rankings + distribution; S3 = output format.
3. **Split by capability lifecycle**: S1 computes the spreads; S2 ranks and shapes them; S3 formats the output.
4. **Closure story**: S3 returns the complete JSON output with audit trail.

### Bad Splits (Avoid)

- "Discount/premium" + "Spread rankings" as two stories. They are the same capability — the spread output.

### Story Line Format

Story IDs follow `VX.Y.SN`. Each story is independently compilable and testable.
