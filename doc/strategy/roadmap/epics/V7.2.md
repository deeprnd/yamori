# V7.2: Covariance Estimation and Correlation Analysis

**Labels:** `type/epic`, `type/feature`, `area/investing`
**GitHub Issue:** TBD

<!-- One paragraph: what complete feature this epic delivers and why now.-->

V7.1 registered BLAS and LAPACK as graph-resolvable formula nodes. V7.2 puts them to work: computing sample, rolling, exponentially weighted, and Ledoit-Wolf shrinkage covariance matrices from return series. Covariance is the single most important input for every downstream portfolio analytics workflow — risk decomposition, factor models, and optimization all consume it. This epic makes covariance estimation a first-class graph node, computable with BLAS-accelerated primitives and deterministic under Yamori's execution policy.

## Product Intent

Compute covariance matrices from return series using BLAS Level 2/3 primitives and LAPACK eigenvalue decomposition for shrinkage estimation. Deliver sample, rolling, exponentially weighted, and Ledoit-Wolf shrinkage estimators, all as graph-resolvable formula nodes. Rolling covariance uses shared-memory windows to avoid reallocation. Deterministic execution policy pins the algorithm variant, shrinkage intensity method, and reduction order.

## Users And Jobs

- [Quantitative analyst]: Compute covariance matrices for 100+ asset portfolios using shrinkage estimation, with deterministic reproducibility.
- [Portfolio manager]: Use rolling covariance to track how correlation structure evolves over time.
- [Risk engineer]: Validate that shrinkage estimation produces stable covariance matrices under stress scenarios.

## Success Metrics

- Sample, rolling, exponentially weighted, and Ledoit-Wolf shrinkage covariance matrices computed from return series.
- All operations use BLAS Level 2/3 primitives for efficiency.
- Rolling covariance uses shared-memory windows to avoid reallocation.
- Shrinkage estimation uses LAPACK eigenvalue decomposition for spectral transformation.
- Deterministic execution policy pins algorithm variant, shrinkage method, and reduction order.
- Bit-identical results across all four target platforms.

## Demo Moment

- Command or flow: `tickoni analysis covariance --method=shrinkage --input=returns.csv --shrinkage=ledoit-wolf`
- Expected result: Ledoit-Wolf shrinkage covariance matrix computed deterministically, with eigenvalue decomposition applied via registered LAPACK backend.
