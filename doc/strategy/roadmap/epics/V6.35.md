This epic integrates TA-Lib as Yamori's first post-valuation backend, establishing an indicator registry that maps Yamori operation identifiers to TA-Lib function handles. Every technical indicator in V6.2–V6.5 depends on this registry: without it, there is no way to discover, parameterize, or execute indicators through the dependency graph.

## Product Intent

Integrate TA-Lib into Yamori's backend router and establish the indicator registry that maps Yamori operation identifiers to TA-Lib function handles with their parameter requirements. This enables all technical indicators to be registered as named formula nodes on the dependency graph, proving the M1 runtime architecture serves technical analysis the same way it serves Damodaran valuation.

## Users And Jobs

- [Investment analyst]: Access technical indicators alongside valuation models through the same Yamori interface.
- [Engineer]: Extend Yamori's backend router to support TA-Lib as a new computational library.
