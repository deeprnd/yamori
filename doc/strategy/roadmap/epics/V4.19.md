# V4.19: Relative Valuation Metrics

**Labels:** `type/epic`, `type/feature`, `area/investing`
**GitHub Issue:** TBD

A peer set with valuations is not enough — the analyst needs to know: is Company A cheap or expensive relative to its peers? V4.19 computes discount/premium to peer median for intrinsic value, implied multiples (P/E, P/B, EV/EBITDA), and yield measures (E/P, E/EBITDA). It calculates percentile ranks within the peer set for each metric. It handles edge cases: peer sets with only 2-3 companies, single-outlier distortion, and missing data gaps. The outcome is that every company in the peer set is positioned relative to its peers — not just an absolute intrinsic value, but a relative discount/premium that answers the institutional question: "Is this cheap or expensive?"

## Product Intent

Deliver the relative valuation metrics engine: compute discount/premium to peer median for intrinsic value, implied multiples (P/E, P/B, EV/EBITDA), and yield measures (E/P, E/EBITDA). Calculate percentile ranks within the peer set for each metric. Handle edge cases (small peer sets, outlier distortion, missing data gaps). The outcome is a complete relative-positioning layer that transforms raw valuations into institutional-grade comparative analysis.

## Users And Jobs

- [Investment analyst]: See whether Company A trades at a 23% discount to peer median intrinsic value, with percentile ranks for all multiples and yields.
- [Compliance reviewer]: Verify that discount/premium calculations use peer medians (not means, which are outlier-sensitive), that percentile ranks are correctly computed, and that edge cases (2-3 companies, outliers) are handled.
- [Engineer]: Add new relative metrics (e.g., discount to peer mean, z-scores) as policy-configurable options without modifying existing calculations.
- [Tickoni tile]: Consume `relativeMetrics(peer_set_results)` as a callable pivot that returns discount/premium, percentile ranks, and yield measures for every company.

## Success Metrics

- Discount/premium to peer median: intrinsic value, implied multiples (P/E, P/B, EV/EBITDA), and yield measures (E/P, E/EBITDA).
- Percentile ranks: computed within the peer set for each metric.
- Peer median (not mean): outlier-resistant relative positioning.
- Edge cases handled: peer sets with 2-3 companies; single-outlier distortion; missing data gaps.
- All relative metrics carry the full audit trail from M1-M3.
- Deterministic: same peer set produces identical relative metrics across runs.

## Demo Moment

- Command or flow: `tickoni batch run --peers <peer_set_file> --relative`
- Expected result: A peer-set valuation table with discount/premium to median, percentile ranks, and yield measures for every company.

### How Many Stories?

Four stories: discount/premium (S1), yields + percentiles (S2), edge cases (S3), and audit trail + determinism (S4). The scope is relative positioning — essential for comparative analysis.

### Decomposition Rules

1. **Independent delivery**: Each story produces verifiable relative metrics.
2. **One capability per story**: S1 = discount/premium; S2 = yields + percentiles; S3 = edge cases; S4 = audit trail.
3. **Split by capability lifecycle**: S1–S2 compute the metrics; S3 handles edge cases; S4 ensures audit integrity.
4. **Closure story**: S4 ensures all relative metrics carry the full audit trail and are deterministic.

### Bad Splits (Avoid)

- "Discount/premium" + "Yield measures" as two stories. They are the same capability — relative metrics computed from peer-set valuations.

### Story Line Format

Story IDs follow `VX.Y.SN`. Each story is independently compilable and testable.
