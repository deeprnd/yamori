V7.4 decomposed risk; V7.5 optimizes it. Portfolio optimization is the crown jewel of quantitative finance: finding the weights that maximize return for a given level of risk (or minimize risk for a given return). This epic implements Markowitz mean-variance, minimum variance, maximum Sharpe, risk parity, Black-Litterman, and constrained optimization — all powered by LAPACK linear solvers and quadratic programming routines. Each problem is a formula node accepting expected returns, covariance, and constraints, producing optimized weights and performance metrics.

## Product Intent

Implement mean-variance optimization (Markowitz), minimum variance, maximum Sharpe, risk parity, Black-Litterman, and constrained optimization (long-only, sector limits, turnover) from LAPACK linear solvers and quadratic programming routines. Each optimization problem is a formula node accepting expected returns, covariance matrix, and constraints. Output: optimized weights, expected return, risk, Sharpe ratio, and constraint satisfaction status. Deterministic execution policy pins the solver algorithm and convergence tolerance.

## Users And Jobs

- [Portfolio manager]: Optimize portfolio weights under various objectives (max Sharpe, min variance, risk parity, Black-Litterman).
- [Risk manager]: Verify that optimized portfolios satisfy all constraints (long-only, sector limits, turnover).
- [Quantitative analyst]: Compare optimization results across different objectives and constraints.
