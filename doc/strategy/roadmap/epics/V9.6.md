# V9.6: Derivatives Demo and Cross-Domain Composition

**Labels:** `type/epic`, `type/enhancement`, `type/documentation`, `area/finance`, `area/build`
**GitHub Issue:** TBD

V9.6 closes M9 (Options and Derivatives) by running a complete derivatives workflow end-to-end: option pricing → exotic pricing → fixed income → volatility surfaces → yield curves, all through the same dependency graph used by the Damodaran valuation engine (M2) and the TA-Lib indicator framework (M6). Demonstrates that the same M1 runtime serves three distinct domains (valuation, technical analysis, derivatives) with fundamentally different numerical methods — closed-form, tree-based, Monte Carlo, finite-difference, and bootstrapping interpolation. Produces deterministic, bit-identical results across all four target platforms. Validates that derivatives node sets operate independently on the same graph, and that the yield curve infrastructure feeds back into Damodaran cost-of-debt and risk-free rate lookups.

## Product Intent

Run a complete derivatives workflow end-to-end through Yamori's dependency graph: European/American option pricing (V9.2) → exotic option pricing (V9.3) → fixed income instrument pricing (V9.4) → volatility surface construction (V9.5) → yield curve management (V9.5), all through the same dependency graph used by the Damodaran valuation engine (M2) and the TA-Lib indicator framework (M6). Demonstrate that the same M1 runtime serves three distinct domains with fundamentally different numerical methods (cash flow projection, signal processing, closed-form pricing, simulation, bootstrapping). Produce deterministic, bit-identical results across all four target platforms. Validate that derivatives node sets operate independently on the same graph. This is the final M9 epic — the proof that Yamori's runtime generalizes beyond a single methodology.

## Users And Jobs

- [Quantitative analyst]: Run a complete derivatives workflow — European/American options, exotics, fixed income, volatility surfaces, yield curves — all through the same dependency graph and interface.
