
# V7.3: Factor Models

**Labels:** `type/epic`, `type/enhancement`, `area/finance`
**GitHub Issue:** #44

<!-- One paragraph: what complete feature this epic delivers and why now.-->

V7.2 produced covariance matrices from return series. V7.3 extracts the latent structure: principal components via SVD, factor loadings, and factor regressions using normal equations. Factor models are the bridge between raw returns and portfolio analytics — they enable risk decomposition (V7.4) and portfolio optimization (V7.5) by reducing high-dimensional return data to a small set of interpretable drivers. This epic supports both user-defined factors (market, size, value, momentum) and data-driven factors (PCA-based), all as graph-resolvable formula nodes.

## Product Intent

Implement principal component analysis (PCA) via SVD (LAPACK DBDSDC), factor extraction from covariance matrices, and factor regression (OLS via normal equations using BLAS GEMM). Support user-defined factor models (market, size, value, momentum) and data-driven models (PCA-based). Factor loadings and residuals become formula nodes on the dependency graph. Factor covariance matrices feed risk decomposition (V7.4) and portfolio optimization (V7.5).

## Users And Jobs

- [Quantitative analyst]: Build PCA-based factor models from return data or specify custom factor loadings (market, size, value, momentum).
- [Portfolio manager]: Use factor models to understand what drives portfolio returns and risk.
- [Researcher]: Compare PCA-derived factors against standard factor models (Fama-French, etc.).
