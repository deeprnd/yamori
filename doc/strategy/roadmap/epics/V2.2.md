
# V2.2: Historical Metrics and ROIC

**Labels:** `type/epic`, `type/enhancement`, `area/finance`
**GitHub Issue:** TBD

Computes NOPAT from EBIT × (1 − tax), derived invested capital from balance-sheet series, historical ROIC per period, net reinvestment, and reinvestment rate. Applies outlier filtering (negative and 3× median exclusion via GSL Statistics) to derive sustainable ROIC and reinvestment rate inputs for the growth model. All computations expressed as formula nodes on the dependency graph.

## Product Intent

Deliver historical metrics computation: NOPAT, invested capital, ROIC, net reinvestment, and reinvestment rate — all derived from financial statements and expressed as formula nodes on the dependency graph. Outlier filtering (GSL Statistics) derives sustainable ROIC and reinvestment rate inputs for the growth model. The outcome is a clean series of historical performance metrics that serve as the foundation for the growth model and valuation.

## Users And Jobs

- [Investment analyst]: View historical NOPAT, ROIC, and reinvestment rate series derived from financial statements, with outlier filtering applied.
- [Compliance reviewer]: Verify that each historical metric traces to a specific financial statement line item and that outlier filtering follows the documented methodology.
- [Engineer]: Add new historical metric formula nodes to the dependency graph without modifying existing metrics.
- [Tickoni tile]: Consume `historicalMetrics(data)` as a callable pivot that returns structured historical performance data with provenance.

## Success Metrics

- NOPAT computed from EBIT × (1 − tax rate) per period.
- Invested capital derived from balance-sheet series (total assets − non-interest-bearing current liabilities).
- ROIC per period: NOPAT / average invested capital.
- Net reinvestment per period: NOPAT − dividends + changes in working capital.
- Reinvestment rate: net reinvestment / NOPAT.
- Outlier filtering: negative values excluded; values exceeding 3× median excluded via GSL Statistics.
- All computations expressed as formula nodes on the dependency graph from V1.1.

## Demo Moment

- Command or flow: `tickoni valuation metrics STLA --historical 5`
- Expected result: A table showing 5 years of NOPAT, invested capital, ROIC, net reinvestment, and reinvestment rate for STLA, with outlier-filtered sustainable values.

### How Many Stories?

Five stories: NOPAT (S1), invested capital (S2), ROIC/reinvestment (S3), outlier filtering (S4), and sustainable values (S5). The scope is historical metrics derivation — the foundation for growth modeling.

### Decomposition Rules

1. **Independent delivery**: Each story compiles and produces a verifiable metric series.
2. **One capability per story**: S1 = NOPAT; S2 = invested capital; S3 = ROIC/reinvestment; S4 = filtering; S5 = sustainable values.
3. **Split by capability lifecycle**: S1–S3 compute raw metrics; S4–S5 derive sustainable inputs.
4. **Closure story**: S5 returns sustainable values — the evidence layer for the growth model.

### Bad Splits (Avoid)

- "NOPAT" + "Invested capital" as separate epics. They are part of the same financial performance framework.
- "ROIC" + "Reinvestment rate" as two stories. They are the same performance analysis.

### Story Line Format

Story IDs follow `VX.Y.SN`. Each story is independently compilable and testable.
