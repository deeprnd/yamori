# V4.17: Random Sampling

**Labels:** `type/epic`, `type/enhancement`, `area/finance`
**GitHub Issue:** TBD

M1-M3 valuations use fixed assumptions. M4 adds uncertainty quantification via Monte Carlo, and the first step is reproducible random sampling of those assumptions. V4.17 generates reproducible samples for uncertain valuation assumptions using GSL's explicit seeded generator lifecycle and backend selection. It produces deterministic random streams from an explicit valuation seed. Distribution samples for growth, margin, WACC, ROIC come from configured Gaussian, log-normal, and uniform distributions. Hard methodology constraints are applied to sampled values via Arrow comparisons and conditional selection. The outcome is that every Monte Carlo simulation starts from a controlled, auditable, reproducible random stream — no ad-hoc assumptions.

## Product Intent

Deliver reproducible random sampling for uncertain valuation assumptions: use GSL's seeded generator lifecycle to produce deterministic random streams from an explicit valuation seed, sample distributions for growth, margin, WACC, ROIC (Gaussian, log-normal, uniform), and apply hard methodology constraints via Arrow comparisons and conditional selection. The outcome is a controlled, auditable, reproducible random stream that serves as the foundation for all Monte Carlo simulations.

## Users And Jobs

- [Quantitative analyst]: Generate reproducible random samples of valuation assumptions from configured distributions with hard methodology constraints applied.
- [Compliance reviewer]: Verify that the random seed is explicit, that the GSL backend is deterministic, and that constraint application is auditable.
- [Engineer]: Add new distributions (e.g., beta, Pareto) as policy-configurable options without modifying the core sampling pipeline.
- [Tickoni tile]: Consume `sampleAssumptions(seed, distributions, constraints)` as a callable pivot that returns a deterministic stream of sampled assumption sets.

## Success Metrics

- Reproducible sampling: deterministic random streams from an explicit valuation seed.
- Distribution support: Gaussian, log-normal, and uniform distributions configured per assumption.
- Constraint application: hard methodology constraints via Arrow comparisons and conditional selection.
- GSL integration: explicit seeded generator lifecycle with backend selection.
- Auditable: every sampled set carries the seed, backend, and distribution configuration.
- Deterministic: same seed, backend, and sample count produce identical outputs across runs.
