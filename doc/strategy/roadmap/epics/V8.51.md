V8.4 delivers FFT-based spectral analysis through FFTW's transform engines. By decomposing financial time series into frequency components, it separates trend, cycle, and noise — enabling cycle detection, spectral density estimation, and frequency-domain filtering. This transforms raw price data into actionable frequency-domain signals: the bridge between raw market data and quantitative insight.

## Product Intent

Deliver FFT-based spectral analysis via FFTW's real/complex DFT, DCT, DST, and multi-dimensional transforms. Decompose financial time series into frequency components — separating trend, cycle, and noise in price series. Estimate spectral density for cycle detection. FFTW plan-based execution ensures deterministic plan selection (quality/pattern/measure strategies). Deterministic execution policy pins the transform type, plan strategy, and in-place vs. out-of-place execution. Output: transformed series (frequency domain), spectral density, and identified cycle periods.

## Users And Jobs

- [Quantitative analyst]: Decompose a price series into trend, cycle, and noise components using FFTW's real DFT — then identify dominant cycle periods via spectral density estimation.
- [Technical analyst]: Apply DCT/DST transforms to price data for signal compression and denoising, using plan-based execution for deterministic results.
- [Data scientist]: Compare forward and inverse FFT reconstructions to validate signal decomposition fidelity.
- [Tickoni tile]: Consume `fftTransform(series, direction, strategy)` as a callable pivot that returns frequency-domain series and spectral density.

## Dependencies And Decisions

- V8.4 depends on V8.1 (FFTW backend registration).
- V8.4 feeds into V8.5 (spectral filtering and cycle decomposition use FFT outputs).
- D45: FFTW plan quality strategy is the default (highest accuracy); pattern strategy for regularly-spaced data; measure strategy for one-time transforms.
- D46: In-place execution is the default (memory-efficient); out-of-place for large datasets where memory alignment matters.
