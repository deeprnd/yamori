# V8.5: Spectral Filtering and Cycle Decomposition

**Labels:** `type/epic`, `type/enhancement`, `area/finance`, `area/build`
**GitHub Issue:** TBD

V8.5 consumes FFT outputs (V8.4) to perform financial signal filtering and cycle decomposition. By removing high-frequency noise, isolating specific frequency bands (short-term cycles, medium-term trends, long-term cycles), and reconstructing filtered signals via inverse FFT, it turns raw frequency-domain data into actionable trading signals. Bandpass filtering, low-pass filtering, and spectral whitening are the core techniques — cycle detection identifies dominant periods in price series using spectral peak analysis.

## Product Intent

Deliver financial signal filtering and cycle decomposition using FFT outputs. Remove high-frequency noise, isolate specific frequency bands (short-term cycles, medium-term trends, long-term cycles), and reconstruct filtered signals via inverse FFT. Implement bandpass filtering, low-pass filtering, and spectral whitening. Cycle detection identifies dominant periods in price series using spectral peak analysis. Deterministic execution policy pins the filter type, cutoff frequencies, and FFTW plan strategy. Output: filtered series, identified cycle periods, and spectral peak significance measures.

## Users And Jobs

- [Technical analyst]: Apply bandpass filtering to isolate a specific cycle band (e.g., 20–60 day cycles) from price data, then reconstruct the filtered signal via inverse FFT.
- [Quantitative analyst]: Perform cycle detection on a price series using spectral peak analysis — identify the dominant periods and their significance measures.
- [Systematic trader]: Use low-pass filtering to remove high-frequency noise from a signal, then apply the cleaned signal to a trading strategy.
- [Tickoni tile]: Consume `spectralFilter(series, filterType, cutoffFrequencies)` as a callable pivot that returns filtered series and identified cycle periods.
