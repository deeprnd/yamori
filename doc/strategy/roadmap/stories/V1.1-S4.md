# V1.1.S4: Formula-to-Arrow adapter — map Yamori formula nodes to Arrow Compute function identifiers

**Labels:** `type/story`, `area/platform`, `type/feature`
**GitHub Issue:** TBD

Translate Yamori formula operation identifiers into Arrow Compute function calls, enabling the formula graph to be executed against Arrow data arrays.

## Product Outcome

Every Yamori formula operation (divide, multiply, subtract, add, and any future operations) maps to a corresponding Arrow Compute function. This adapter is the bridge between the formula registry's abstract operations and the concrete Arrow Compute engine that performs the actual numerical computation.

## User Story

As an investment analyst, I want the system to translate formula operations into Arrow Compute calls, so that the formula composer can leverage Arrow's optimized data processing without implementing numerical kernels from scratch.

## User Story

As a data researcher, I want to add new financial formulas that automatically map to Arrow Compute functions, so that I can define new metrics without understanding or touching the computation engine.

## Scope

- In scope: Operation-to-Arrow mapping table (comptime array or enum-to-string mapping). Arrow Compute function identifier lookup by Yamori operation name. Support for basic operations: add, subtract, multiply, divide. Error handling for undefined operations. Input/output array type validation (Arrow float64 for numeric results).
- Out of scope: Named formula definition (S1). Dependency resolution (S2). Cycle detection (S3). Graph traversal (S5). Re-evaluation (S6). Provenance (S7).

## Preconditions And Assumptions

- Arrow Compute library is available and linked.
- Operation identifiers use Arrow Compute function names (e.g., "add", "subtract", "multiply", "divide").
- All numeric operations work on float64 Arrow arrays.

## Acceptance Criteria

- [ ] Given a formula operation "divide", when the adapter looks up the Arrow function, then it returns the Arrow Compute function identifier "divide".
- [ ] Given a formula operation "multiply", when the adapter looks up the Arrow function, then it returns "multiply".
- [ ] Given a formula operation "add", when the adapter looks up the Arrow function, then it returns "add".
- [ ] Given a formula operation "subtract", when the adapter looks up the Arrow function, then it returns "subtract".
- [ ] Given an unknown operation "foobar", when the adapter looks up the Arrow function, then it returns Error (undefined operation).
- [ ] Given input arrays of type float64, when a formula is executed via the adapter, then the output array is also float64.
