# M1: Damodaran Core — Intrinsic Value Engine

## Description

Delivers a working Damodaran-style FCFF discounted cash flow engine that accepts a company's financial statements and policy inputs and produces a per-share intrinsic value estimate with full WACC computation, three-stage growth modeling, and equity bridge — the first complete valuation loop Tickoni can execute.

```text
financial statements + policy -> DCF -> intrinsic value per share
```

M1 closes the core valuation loop: the engine reads structured financial data, computes every Damodaran Step 2 (WACC with bottom-up beta, revenue-weighted CRP, cost of debt) and Step 3 (three-stage growth from ROIC × reinvestment), projects ten years of FCFF, discounts to present value, applies the Gordon terminal value, bridges to equity value, and outputs per-share intrinsic value in the reporting currency. This is the first Tickoni capability that can produce an auditable, deterministic valuation from raw financial data.

## Included Epics

### Epic V1.1 — Core types, policy, and valuation runner

Establishes the domain types (`Money<C>`, `Rate`, `Period`, `DataPoint<T>`), the `ValuationPolicy` record, the error model (`!Error` throughout), and the pure `runValuation()` function that is the structural pivot for all downstream analyses.

### Epic V1.2 — Historical metrics and ROIC

Computes NOPAT from EBIT × (1 − tax), derived invested capital from balance-sheet series, historical ROIC per period, net reinvestment, and reinvestment rate. Applies outlier filtering (negative and 3× median exclusion) to derive sustainable ROIC and reinvestment rate inputs for the growth model.

### Epic V1.3 — Cost of capital and WACC

Calculates bottom-up beta from sector unlevered beta and subject-company D/E, revenue-weighted country risk premiums over the 13-block geographic taxonomy, cost of equity via CAPM, cost of debt via synthetic-rating ladder, capital weights, and WACC. Every component is traceable to a Damodaran dataset.

### Epic V1.4 — Three-stage growth model and FCFF projection

Derives high-growth rate from sustainable ROIC × sustainable reinvestment, generates continuous linear transition paths for growth, ROIC, and tax rate (GSL interpolation), constrains terminal growth to risk-free rate, projects ten-year EBIT → NOPAT → reinvestment → FCFF schedule.

### Epic V1.5 — Terminal value, equity bridge, and per-share value

Computes discount factors via iterative multiplication (no `std.math.pow`), discounts FCFF to present value, calculates Gordon terminal value from year-11 FCFF, bridges operating asset value to equity value via debt/cash/non-operating assets, divides by shares outstanding, applies single FX translation.

## Why This Is A Milestone

M1 transforms Tickoni from a data repository into a valuation engine. No single epic produces a runnable valuation; only when V1.1 through V1.5 ship together does the complete Damodaran loop execute end-to-end. M2 and M3 depend on this loop as their execution substrate. This is not a demo — it is the first Tickoni capability that can be audited by a third party against Damodaran's published methodology.

## Completion Signal

A user can run `tickoni valuation run <company>` with financial statements, policy, and dataset inputs and receive a per-share intrinsic value output that passes all golden-test fixtures from the methodology. The `runValuation()` function is pure (no I/O imports in `valuation_core`), and the deterministic pipeline produces bit-identical results across Linux x86, Linux ARM, macOS ARM, and Windows x86 when fed the same inputs and dataset manifest.

## Summary

Tickoni does not estimate — it computes. M1 is where financial statements become intrinsic value through a complete Damodaran DCF: WACC from fundamentals, growth from ROIC × reinvestment, ten-year FCFF projection, Gordon terminal value, and equity bridge. Every number is traceable to a published dataset. No assumption enters the engine that code could have produced. This is the first proof that Tickoni can deliver auditable valuation at scale.
