# M3: Cross-Checks And Uncertainty — Reverse DCF, Sensitivity, And Scenarios

## Description

Adds uncertainty quantification to M1's deterministic valuation by implementing reverse DCF, relative-multiple cross-checks, sensitivity matrices, and scenario analysis — transforming a single point estimate into a bounded, auditable range.

```text
deterministic DCF -> reverse DCF, sensitivity grid, scenarios -> bounded value
```

M3 answers the question every professional valuation must: "What does the market imply, and how sensitive is our value to key assumptions?" Reverse DCF solves for the Stage 1 growth rate implied by the current market price using fixed-count bisection. Sensitivity matrices show how value changes across WACC/growth grids. Scenarios (bull, base, bear, stress) exercise the same pipeline with different policy inputs. Cross-checks against relative multiples (implied P/E, P/S, EV/EBITDA) and exit-multiple terminal value validate the DCF's internal consistency.

## Included Epics

### Epic V3.12 — Reverse DCF

Solves for the Stage 1 growth rate that makes the DCF output equal the current market price using GSL's fixed-count bisection solver (100 iterations, not tolerance-based). Holds all other assumptions fixed. Returns the implied growth rate and corresponding intrinsic value. Proves whether the market is pricing in more or less growth than the fundamentals support.

### Epic V3.13 — Relative-multiple cross-checks

Calculates implied P/E, implied P/S, and implied EV/EBITDA from the intrinsic equity value. Computes exit-multiple terminal value from supplied EBITDA and industry exit multiples. Ensures multiple selection matches adjustment state (EV/EBITDAR&D when R&D is capitalized). Validates cross-checks against audit severity rules.

### Epic V3.14 — Sensitivity matrices

Evaluates the complete valuation pipeline over a two-dimensional WACC/growth grid, producing a sensitivity matrix of intrinsic values. Each cell re-runs `runValuation()` with no new formula implementation. The matrix is deterministic and reproducible, anchored to the same dataset manifest and policy framework.

### Epic V3.15 — Scenario analysis

Defines and executes bull, base, bear, and stress scenarios as complete input sets (different growth assumptions, WACC parameters, geographic exposure, moat spread). Runs the identical pipeline for each scenario, producing a scenario distribution. All scenarios share the same base-case preservation: enabling scenarios does not change the deterministic M1 output.

### Epic V3.16 — Audit checks and severity enforcement

Implements Step 10 audit assertions with severity levels (Error, Warn, Info). Any Error blocks rendering a conclusion. Validates: terminal growth ≤ risk-free rate, WACC − g ≥ 100bp, currency consistency, single FX date, CRP derived from default spreads (not read raw), geographic coverage, no invented inputs, FCFF reconciliation, terminal value share < 75%, moat spread supported by historical ROIC − WACC spread.

## Why This Is A Milestone

M3 transforms Tickoni from a calculation engine into an audit-ready valuation system. A single intrinsic value number is not defensible without cross-checks and uncertainty bounds. M3 closes the loop: the engine now produces not just a number but the evidence that the number is reasonable, the assumptions it depends on, and the range within which it likely falls. This is what distinguishes professional-grade valuation from toy DCF implementations.

## Completion Signal

Running a company valuation through M3 produces: (1) a deterministic per-share intrinsic value from M1/M2, (2) a reverse DCF implied growth rate with interpretation, (3) a sensitivity matrix showing value across WACC/growth grids, (4) scenario distributions (bull/base/bear/stress), and (5) audit assertions with severity flags. The reverse DCF output is bit-identical across runs for the same market price. The sensitivity matrix covers the full required grid. Scenario outputs preserve the base-case value exactly.

## Summary

Value without context is opinion. M3 gives Tickoni's intrinsic value the context it needs: what the market implies, how sensitive the number is to key assumptions, and whether the valuation holds up under stress. Reverse DCF reveals whether the current price embeds more or less growth than fundamentals support. Sensitivity grids show the value landscape. Scenarios test the thesis. Cross-checks against multiples catch internal inconsistencies. This is the difference between a calculation and a case.
