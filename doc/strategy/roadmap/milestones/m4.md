# M4: Comparative Analysis — Multi-Company Benchmarking And Peer Valuation

## Description

Extends M1-M3 from single-company valuation to multi-company comparative analysis, enabling peer-set benchmarking, valuation spread visualization, and sector-relative positioning — the capability that turns Tickoni from an analyst's calculator into a portfolio-grade research platform.

```text
single DCF -> peer set -> relative valuation -> spread analysis
```

M4 answers the question every institutional analyst asks: "Is this company cheap or expensive relative to its peers?" It runs M1-M3 valuations across an entire peer set, computes valuation spread metrics (discount/premium to peer median), generates sector-relative positioning, and identifies outliers — all deterministically, with every individual valuation carrying the same audit trail from M2.

## Included Epics

### Epic V4.17 — Peer-set management and company catalog

Defines peer-set membership as a sourced input (persisted, not re-guessed per run). Manages the company catalog with canonical identifiers (ISO 10383 MIC, ISO 4217 currency, ISIN/CUSIP), Damodaran sector assignments, and geographic exposure records. Ensures sector assignments are consistent across valuations to prevent beta drift.

### Epic V4.18 — Batch valuation runner

Executes M1's `runValuation()` pipeline across a peer set in a single batch operation. Shares dataset manifest lookups and policy objects across runs to minimize redundant computation. Produces a peer-set valuation table with all M1/M2/M3 outputs for every company, enabling cross-company comparison from a single execution.

### Epic V4.19 — Relative valuation metrics

Computes discount/premium to peer median for intrinsic value, implied multiples (P/E, P/B, EV/EBITDA), and yield measures (E/P, E/EBITDA). Calculates percentile ranks within the peer set for each metric. Handles edge cases: peer sets with only 2-3 companies, single-outlier distortion, and missing data gaps.

### Epic V4.20 — Valuation spread visualization

Generates structured output showing valuation spreads: which companies trade at discount/premium to intrinsic value, which have the widest/narrowest spreads, and how the peer distribution looks. Outputs are machine-readable (JSON tables) for downstream consumption by Tickoni tiles or external consumers.

### Epic V4.21 — Sector-relative positioning

Maps peer-set results to Damodaran sector benchmarks. Compares computed WACC, ROIC, and growth rates against sector medians from Damodaran's published industry data. Flags companies with significant deviation from sector norms and validates whether those deviations are supported by company-specific evidence.

## Why This Is A Milestone

M4 transforms Tickoni from a single-company tool into a research platform. M1-M3 prove the valuation engine works for one company; M4 proves it works at scale across a peer set with consistent methodology. The comparative capability is what makes Tickoni defensible against spreadsheet-based workflows: the same deterministic pipeline, same audit trail, same data provenance applied uniformly across 50 companies simultaneously. This is a platform capability, not just a feature.

## Completion Signal

A peer set of at least 5 companies can be evaluated in a single batch run. The output includes per-company intrinsic values, implied multiples, and audit assertions from M3, plus peer-relative metrics (discount/premium to median, percentile ranks, sector benchmarks). Running the batch twice with the same inputs produces bit-identical results for every company. Sector benchmark comparisons use the same Damodaran dataset vintages.

## Summary

The market prices companies in relation to each other. M4 gives Tickoni the same comparative lens: run valuations across a peer set, compute relative discounts and premiums, and flag outliers. This is not relative valuation in the weak sense — every individual valuation in the peer set is fully audited (M2 adjustments, M3 cross-checks, audit assertions). The relative metrics inherit the full audit trail. Tickoni doesn't just say "Company A is cheap"; it says "Company A trades at a 23% discount to peer median intrinsic value, with WACC 80bps below sector and ROIC spread of 420bps — supported by R&D capitalization in the peer set."
