# M9: Options and Derivatives — The Full Spectrum of Financial Computation

## Description

M9 extends Yamori to options, derivatives, and fixed income by integrating QuantLib. It delivers deterministic pricing of options (European, American, exotic), interest rate instruments (swaps, bonds, cap/floor), and structured products — the second post-M4 domain after technical analysis.

QuantLib's pricing engines cover a broad algorithmic spectrum: closed-form solutions (Black-Scholes), tree-based methods (binomial trees), Monte Carlo simulation, and finite-difference discretization. Yamori pins *every* algorithmic choice for reproducibility. The same deterministic execution policy that governs a DCF also governs a Monte Carlo derivative engine, ensuring consistent behavior across all numerical methods.

```text
underlying series + QuantLib -> deterministic derivatives pricing
```

M9 proves Yamori's runtime architecture handles instruments with closed-form solutions and those requiring numerical methods (Monte Carlo, finite-difference). The dependency graph (M1 Epic V1.1) serves pricing formulas the same way it serves valuation and technical indicators: each instrument type is a named node resolving in topological order over input parameters. QuantLib provides the pricing kernels (Black-Scholes, Binomial Trees, Monte Carlo engines); Yamori provides the graph, the backend router, the shared-memory representation, and the deterministic execution policy. Fixed income instruments also provide the yield curve infrastructure useful for Damodaran cost-of-debt and risk-free rate lookups (M2).

## Library Dependencies

**Library: QuantLib** — Options pricing (European, American, Barriers, Asians, Lookbacks), fixed income (bonds, swaps, cap/floor, swaptions), numerical methods (Monte Carlo, finite-difference, tree-based), volatility surfaces, and yield curve constructions. QuantLib provides the pricing kernels; Yamori provides the graph, routing, and determinism.

## Included Epics

### Epic V9.1 — QuantLib integration and pricing registry

Integrates QuantLib as a backend in Yamori's unified backend router (M1 Epic V1.2). Establishes a QuantLib pricing registry that maps Yamori operation identifiers to QuantLib pricing engines. Resolves instrument requirements: European options need strike, maturity, dividend yield; American options need early-exercise boundary; fixed income instruments need yield curve. Each registered instrument becomes a named formula node on the dependency graph.

### Epic V9.2 — Equity option pricing

Implements European options (call/put) via Black-Scholes-Merton and American options via binomial trees (CRR, Bjerksund-Stensland) from QuantLib. Each option type is a formula node accepting underlying price, strike, time-to-maturity, volatility, dividend yield, and risk-free rate, producing fair value and full Greeks (Delta, Gamma, Vega, Theta, Rho). Pricing is deterministic: pinned algorithm (closed-form vs. tree), pinned volatility model, pinned grid resolution.

### Epic V9.3 — Exotic option pricing

Implements barrier options (up/out, down/in, etc.), Asian options (average price/average strike), lookback options, and compound options from QuantLib's Monte Carlo and finite-difference engines. These instruments require numerical methods rather than closed-form solutions. Deterministic execution policy pins the RNG seed, sample count, time step discretization, and variance reduction method (antithetic variates, control variates). Output includes fair value, Greeks via finite-difference perturbation, and convergence diagnostics.

### Epic V9.4 — Fixed income instruments

Implements bond pricing (zero-coupon, coupon-bearing, zero-coupon yield curve construction), interest rate swaps, caps, floors, and swaptions from QuantLib. Bond pricing requires yield curve interpolation (linear, cubic, Nelson-Siegel) and day-count convention handling. Swap pricing requires bootstrapping from market quotes. Cap/floor pricing requires volatility surface construction. These instruments also provide yield curve infrastructure useful for Damodaran cost-of-debt and risk-free rate lookups.

### Epic V9.5 — Volatility surface and yield curve management

Builds and manages volatility surfaces (implied vol from market option prices, fitted parametric surfaces) and yield curves (bootstrapped from bonds/swaps/caps, interpolated for pricing). Surfaces and curves are stored as shared-memory objects (M1 Epic V1.3) accessible across processes. Changes to surface/curve inputs produce deterministic re-pricing through the dependency graph. Provenance captures the source data, fitting method, and interpolation scheme.

### Epic V9.6 — Derivatives demo and cross-domain composition

Runs a complete derivatives workflow: option pricing → exotic pricing → fixed income → volatility surfaces → yield curves, all through the same dependency graph used by the Damodaran valuation engine (M2) and the TA-Lib indicator framework (M6). Demonstrates that the same M1 runtime serves three distinct domains. Produces deterministic, bit-identical results across platforms. Validates that derivatives node sets operate independently on the same graph.

## Why This Is A Milestone

M9 is Yamori's second proof that the runtime generalizes beyond a single methodology. Technical analysis (M6) proved signal processing over price series. Derivatives pricing proves numerical computation — Monte Carlo, finite-difference, tree-based methods — under the same deterministic execution policy. QuantLib's pricing engines are algorithmically rich (closed-form, simulation, discretization) and M9 proves Yamori can pin every algorithmic choice for reproducibility. The fixed income module also provides yield curve infrastructure that feeds back into the Damodaran valuation domain (risk-free rate, cost of debt), demonstrating cross-domain utility.

When the same pinning policy governs a closed-form Black-Scholes formula and a Monte Carlo exotic engine, it demonstrates that Yamori is built for production-grade reliability, not research prototypes.

## Completion Signal

All QuantLib instruments (V9.1–V9.5) are registered in the pricing registry and accessible as formula nodes on the dependency graph. European/American/exotic options, fixed income instruments, volatility surfaces, and yield curves all produce deterministic outputs. A derivatives workflow (V9.6) runs end-to-end through the same backend router and deterministic execution policy as the valuation engine (M2) and TA-Lib framework (M6). Results are bit-identical across Linux x86, Linux ARM, macOS ARM, and Windows x86 for the same input data and QuantLib version. All three domains (valuation, technical analysis, derivatives) operate independently on the same graph.

## Summary

M9 proves Yamori handles the full spectrum of financial computation: valuation (cash flow projection), signal processing (technical indicators), and numerical pricing (options, derivatives, fixed income). QuantLib's algorithms are among the most computationally diverse in finance — closed-form, Monte Carlo, tree-based, finite-difference — and Yamori's deterministic execution policy pins every choice. The yield curve infrastructure from fixed income also feeds back into the Damodaran engine, demonstrating cross-domain utility. This is the runtime proving its generality.
