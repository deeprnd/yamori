# M6: Technical Analysis — A General-Purpose Financial Runtime

## Description

M6 extends Yamori from the Damodaran valuation domain (M1–M5) to technical analysis by integrating TA-Lib and building the indicator formula framework. It delivers the first post-M4 domain: MACD, RSI, Bollinger Bands, and other widely-used technical indicators computed deterministically over the same Arrow-backed financial frame used by the valuation engine.

The logical answer to "can Yamori do more than valuation?" is "yes, add more libraries." The psycho-logic insight is deeper: the *same infrastructure* that powers intrinsic valuation also powers signal processing over price series. This isn't a feature addition — it's proof of concept that Yamori is a general financial computation runtime, not a single-domain calculator. The dependency graph defined in M1 serves technical indicators the same way it serves valuation formulas: each indicator is a named node that resolves in topological order. TA-Lib provides the computational kernels; Yamori provides the graph, the backend router, the shared-memory representation, and the deterministic execution policy.

```text
price series + TA-Lib indicators -> deterministic technical signals
```

M6 proves Yamori's runtime architecture (M1) generalizes beyond Damodaran. The dependency graph defined in M1 Epic V1.1 serves technical indicators the same way it serves valuation formulas: each indicator is a named node that resolves in topological order over the input price series. TA-Lib provides the computational kernels; Yamori provides the graph, the backend router, the shared-memory representation, and the deterministic execution policy. This is the first step toward Yamori as a general financial computation runtime, not a single-domain calculator.

## Library Dependencies

**Library: TA-Lib** — Technical analysis indicators: moving averages (SMA, EMA, WMA, DEMA, TEMA, KAMA, MAMA, T3), oscillators (RSI, Stochastic, CCI, ROC, MOM), pattern recognition (candlestick patterns via TA-Lib's pattern API), volatility indicators (Bollinger Bands), trend indicators (ADX, ATR, SAR), and volume indicators (OBV, AD, ADOSC). TA-Lib provides the computational kernels; Yamori provides the graph, routing, and determinism.

## Included Epics

### Epic V6.1 — TA-Lib integration and indicator registry

Integrates TA-Lib as a backend in Yamori's unified backend router (M1 Epic V1.2). Establishes a TA-Lib indicator registry that maps Yamori operation identifiers to TA-Lib function handles. Resolves parameter requirements per indicator: RSI needs period; Bollinger Bands needs period and deviation multiplier; MACD needs fast_period, slow_period, signal_period. Each registered indicator becomes a named formula node on the dependency graph.

### Epic V6.2 — Moving average indicators

Implements simple, exponential, weighted, double/triple exponential, Kaufman, MAMA/T3 moving averages from TA-Lib. Each moving average is a formula node that accepts a price series and period parameter and produces a filtered series. Moving averages are building blocks for higher-level indicators: Bollinger Bands, MACD, and all oscillators depend on them. Deterministic execution policy pins the TA-Lib implementation.

### Epic V6.3 — Oscillator indicators

Implements RSI, Stochastic (Fast/D Slow), Commodity Channel Index (CCI), Rate of Change (ROC), and Momentum (MOM) from TA-Lib. Each oscillator is a formula node over the dependency graph. RSI depends on SMA/EMA (V6.2). Stochastic depends on SMA (V6.2). CCI depends on SMA and mean deviation. Oscillators produce bounded or unbounded signal series.

### Epic V6.4 — Volatility and trend indicators

Implements Bollinger Bands (upper/middle/lower bands from SMA + deviation), Average True Range (ATR), Average Directional Index (ADX), and Parabolic SAR from TA-Lib. Bollinger Bands require a moving average (V6.2) and a standard deviation over the lookback period. ADX requires +DI and -DI. ATR requires true range computation from high/low/close series. These indicators produce volatility envelopes and trend-strength measures.

### Epic V6.5 — Volume indicators and pattern recognition

Implements On-Balance Volume (OBV), Accumulation/Distribution (AD), AD Oscillator (ADOSC), and TA-Lib's candlestick pattern recognition API. Volume indicators produce cumulative or smoothed series from price + volume data. Pattern recognition produces boolean or categorical signals from candlestick formations. Both are formula nodes on the dependency graph.

### Epic V6.6 — Technical analysis demo and cross-domain composition

Runs a complete technical analysis workflow: price series → moving averages → oscillators → volatility indicators → volume indicators, all through the same dependency graph used by the Damodaran valuation engine (M2). Demonstrates that the same M1 runtime serves both domains. Produces deterministic, bit-identical results across platforms. Validates that technical indicators on the same data as a valuation produce no cross-domain interference (they share the graph but use independent node sets).

## Why This Is A Milestone

M6 is Yamori's first proof that the runtime architecture generalizes beyond a single methodology. The Damodaran engine (M1–M5) proved the graph, router, and determinism work for valuation. Technical analysis proves they work for a completely different class of financial computation — signal processing over price series, not cash-flow projection. TA-Lib provides the computational kernels; Yamori provides the graph structure, backend isolation, shared-memory efficiency, and deterministic reproducibility. This milestone establishes the pattern for all future domains: install the library, register indicators as graph nodes, validate determinism.

The deeper message: Yamori isn't a valuation engine with extra steps. It's a general-purpose financial computation runtime that happens to start with valuation.

## Completion Signal

All TA-Lib indicators (V6.1–V6.5) are registered in the indicator registry and accessible as formula nodes on the dependency graph. Moving averages, oscillators, volatility indicators, volume indicators, and candlestick patterns all produce deterministic outputs. A technical analysis pipeline (V6.6) runs end-to-end through the same backend router and deterministic execution policy as the Damodaran engine. Results are bit-identical across Linux x86, Linux ARM, macOS ARM, and Windows x86 for the same input data and TA-Lib version. The Damodaran and TA-Lib node sets operate independently on the same graph.
