# M8: Advanced Analytics — High-Dimensional Integration and Spectral Analysis

## Description

M8 extends Yamori to advanced numerical analytics by integrating Cuba (multidimensional integration) and FFTW (fast Fourier transform). It delivers high-dimensional integration for portfolio Monte Carlo, spectral analysis for cycle detection and signal decomposition, and the final post-M4 domain that rounds out Yamori's computational coverage.

The logical answer to "what's left to compute?" is "everything that's hard." The psycho-logic insight is about *completeness as a signal*. When a system handles the full spectrum of financial numerical methods — cash flow projection, signal processing, numerical pricing, matrix linear algebra, high-dimensional integration, and spectral analysis — it signals that Yamori is not just another tool. It signals that Yamori is a *general-purpose financial computation runtime*. The same dependency graph, backend router, shared-memory infrastructure, and deterministic execution policy serve five domains with fundamentally different mathematical requirements. That's the proof of generality.

```text
multidimensional integration + spectral analysis -> high-dimensional analytics
```

M8 is Yamori's fourth and final post-M4 domain milestone. Cuba provides Monte Carlo and Vegas integration for high-dimensional integrals — problems that are intractable with deterministic quadrature and appear in portfolio risk simulation, exotic derivative pricing, and factor model calibration. FFTW provides fast Fourier transforms for spectral analysis — cycle detection in financial time series, signal decomposition, and frequency-domain filtering. Together, these libraries add the last major class of numerical methods that financial computation requires: high-dimensional integration and spectral analysis. The dependency graph (M1 Epic V1.1) serves these as named formula nodes; the backend router (M1 Epic V1.2) isolates the integration and transform kernels; the shared-memory representation (M1 Epic V1.3) enables zero-copy data sharing for large multidimensional grids.

## Library Dependencies

**Library: Cuba (Vegas, Suave, Divonne, Cuhre)** — Multidimensional Monte Carlo integration (Vegas, Suave) and deterministic adaptive integration (Divonne, Cuhre). Cuba provides variance reduction (stratified sampling, importance sampling, parallel evaluation) and error estimation. Vegas is the workhorse for portfolio Monte Carlo; Cuhre is the choice for smooth integrands requiring high precision.

**Library: FFTW (FFTW3)** — Fast Fourier transform library (real/complex DFT, DCT, DST, multi-dimensional transforms, plan-based execution). FFTW provides the transform kernels; Yamori provides the graph structure and deterministic pinning of transform types and plan strategies.

## Included Epics

### Epic V8.1 — Cuba integration and spectral registry

Integrates Cuba and FFTW as backends in Yamori's unified backend router (M1 Epic V1.2). Establishes a combined registry that maps Yamori operation identifiers to Cuba integration engines and FFTW transform types. Resolves operation requirements: multidimensional integration needs dimension count, integrand function, integration bounds, and error tolerance; FFTW transforms need input array shape, transform direction (forward/inverse), and plan strategy. Each registered operation becomes a named formula node on the dependency graph.

### Epic V8.2 — Monte Carlo integration and portfolio simulation

Implements Vegas and Suave multidimensional Monte Carlo integration from Cuba. Integrates over high-dimensional probability spaces — portfolio value distributions with correlated asset returns, multi-factor risk scenarios, and path-dependent payoff integration. Vegas provides variance reduction via stratified sampling and importance sampling. Suave provides adaptive stratified sampling with automatic dimension reduction. Deterministic execution policy pins the RNG seed, random stream generator, sample count, and stratification strategy. Output includes integral estimate, statistical error, and convergence diagnostics.

### Epic V8.3 — Deterministic integration for pricing and calibration

Implements Divonne and Cuhre deterministic adaptive integration from Cuba. Cuhre is used for smooth integrands requiring high precision: exotic option pricing with smooth payoff functions, factor model calibration via likelihood integration, and valuation sensitivity analysis (Greeks via integration rather than finite-difference). Divonne is used for integrands with known boundary structure. Deterministic execution policy pins the integration algorithm, subdivision strategy, and evaluation budget. Output includes integral estimate, deterministic error bound (not statistical), and evaluation count.

### Epic V8.4 — FFT spectral analysis

Implements real and complex FFT, DCT, DST, and multi-dimensional transforms from FFTW. Financial signal decomposition: separating trend, cycle, and noise components in price series. Spectral density estimation for cycle detection. FFTW plan-based execution ensures deterministic plan selection (quality/pattern/measure strategies). Deterministic execution policy pins the transform type, plan strategy, and in-place vs. out-of-place execution. Output: transformed series (frequency domain), spectral density, and identified cycle periods.

### Epic V8.5 — Spectral filtering and cycle decomposition

Uses FFT outputs for financial signal filtering: removing high-frequency noise, isolating specific frequency bands (short-term cycles, medium-term trends, long-term cycles), and reconstructing filtered signals via inverse FFT. Implements bandpass filtering, low-pass filtering, and spectral whitening. Cycle detection identifies dominant periods in price series using spectral peak analysis. Deterministic execution policy pins the filter type, cutoff frequencies, and FFTW plan strategy. Output: filtered series, identified cycle periods, and spectral peak significance measures.

### Epic V8.6 — Advanced analytics demo and cross-domain composition

Runs a complete advanced analytics workflow: multidimensional portfolio integration (Vegas/Suave) + spectral signal decomposition (FFT) + cycle detection, all through the same dependency graph used by the Damodaran valuation engine (M2), TA-Lib framework (M6), derivatives engine (M9), and portfolio analytics (M7). Demonstrates that the same M1 runtime serves five distinct domains with fundamentally different numerical methods (cash flow projection, signal processing, numerical pricing, matrix linear algebra, high-dimensional integration, spectral analysis). Produces deterministic, bit-identical results across platforms. Validates that all five domains operate independently on the same graph.
