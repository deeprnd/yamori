# V1.2-S7: Dispatch Provenance — Every Operation Records Backend, Inputs, and Output

**Goal:** Ensure every dispatch operation records provenance metadata: backend used, input data (or metadata), and output data.

**Architecture:** A provenance tracking module that captures and stores dispatch event records. Each dispatch call appends a provenance record containing operation name, backend selector, input metadata (length, hash), output metadata (length, hash), and timestamp. The provenance module maintains a bounded buffer of recent dispatch events accessible via the dispatch API.

**Tech Stack:** Zig 0.17, `std.ArrayList`, SHA-256 hashing, `std.time`

```zig
pub const ProvenanceRecord = struct {
    operation_name: []const u8,
    backend_used: BackendPolicy,
    input_count: usize,
    input_lengths: []const usize,
    output_count: usize,
    timestamp_ns: u64,
    success: bool,
    error_message: ?[]const u8,

    pub fn deinit(self: *ProvenanceRecord, gpa: std.mem.Allocator) void {
        if (self.input_lengths.len > 0) {
            gpa.free(self.input_lengths);
            self.input_lengths = &.{};
        }
        if (self.error_message) |msg| {
            gpa.free(msg);
            self.error_message = null;
        }
    }
};
```

## Task 2: Define ProvenanceBuffer ✅

**Objective:** Create the ProvenanceBuffer struct that stores a bounded history of dispatch events.

**Files:**
- Modify: `src/provenance.zig`

**Step 1: Write the ProvenanceBuffer struct**

```zig
pub const ProvenanceBuffer = struct {
    allocator: std.mem.Allocator,
    records: std.ArrayList(ProvenanceRecord),
    max_size: usize,

    pub fn init(gpa: std.mem.Allocator, max_size: usize) ProvenanceBuffer {
        return ProvenanceBuffer{
            .allocator = gpa,
            .records = std.ArrayList(ProvenanceRecord).init(gpa),
            .max_size = max_size,
        };
    }

    pub fn deinit(self: *ProvenanceBuffer) void {
        var it = self.records.itemsIterator();
        while (it.next()) |record| {
            record.*.deinit(self.allocator);
        }
        self.records.deinit();
    }

    pub fn append(self: *ProvenanceBuffer, record: ProvenanceRecord) !void {
        try self.records.append(record);
        
        // Maintain bounded size: remove oldest records
        while (self.records.items.len > self.max_size) {
            var first = self.records.items[0];
            first.deinit(self.allocator);
            _ = self.records.orderedRemove(0);
        }
    }

    pub fn get(self: *const ProvenanceBuffer, index: usize) ?*const ProvenanceRecord {
        if (index < self.records.items.len) {
            return &self.records.items[index];
        }
        return null;
    }

    pub fn count(self: *const ProvenanceBuffer) usize {
        return self.records.items.len;
    }
};
```

## Task 3: Implement ProvenanceCapture Helper ✅

**Objective:** Create a helper that builds ProvenanceRecord from dispatch context.

**Files:**
- Modify: `src/provenance.zig`

**Step 1: Add ProvenanceCapture function**

```zig
pub fn capture(
    gpa: std.mem.Allocator,
    op_name: []const u8,
    backend: BackendPolicy,
    inputs: []const []const f64,
    output_count: usize,
    success: bool,
    error_msg: ?[]const u8,
) !ProvenanceRecord {
    var lengths = try gpa.alloc(usize, inputs.len);
    errdefer gpa.free(lengths);
    
    var i: usize = 0;
    while (i < inputs.len) : (i += 1) {
        lengths[i] = inputs[i].len;
    }
    
    return ProvenanceRecord{
        .operation_name = op_name,
        .backend_used = backend,
        .input_count = inputs.len,
        .input_lengths = lengths,
        .output_count = output_count,
        .timestamp_ns = std.time.milliTimestamp() * 1_000_000,
        .success = success,
        .error_message = error_msg,
    };
}
```

## Task 5: Test Provenance Query ✅

**Objective:** Verify that provenance records can be queried by operation name.

**Files:**
- Modify: `src/provenance.zig`

**Step 1: Add query method to ProvenanceBuffer**

```zig
pub fn findByOperation(self: *const ProvenanceBuffer, op_name: []const u8) ?*const ProvenanceRecord {
    var i: usize = self.records.items.len;
    // Search backwards for most recent match
    while (i > 0) {
        i -= 1;
        if (std.mem.eql(u8, self.records.items[i].operation_name, op_name)) {
            return &self.records.items[i];
        }
    }
    return null;
}

pub fn countByOperation(self: *const ProvenanceBuffer, op_name: []const u8) usize {
    var count: usize = 0;
    for (self.records.items) |record| {
        if (std.mem.eql(u8, record.operation_name, op_name)) {
            count += 1;
        }
    }
    return count;
}
```

```zig
test "End-to-end provenance tracks mixed operations and backends" {
```
