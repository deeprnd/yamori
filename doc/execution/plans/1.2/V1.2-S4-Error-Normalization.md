# V1.2-S4: Error Normalization — All Backend Failures Return Yamori !Error Types

**Goal:** Define Yamori's unified !Error type hierarchy and ensure all backend dispatch paths return these normalized error types instead of raw backend-specific errors.

**Architecture:** A central error module that defines the Yamori error type hierarchy. Each adapter (Arrow, GSL) maps its backend-specific errors to Yamori error types. The dispatch API (S5) catches backend errors and normalizes them before returning to the caller.

**Tech Stack:** Zig 0.17 error sets, error union types, `@errorSetOf`

## Task 1: Define Yamori Error Type Hierarchy

**Objective:** Create the Yamori.Error enum that represents all possible dispatch failures.

**Files:**
- Create: `src/error.zig`
- Test: `src/main.zig` (append test block)

**Step 1: Write the Yamori error type hierarchy**

```zig
pub const YamoriError = error{
    // Operation errors
    UnknownOperation,
    OperationNotSupported,
    InvalidOperationInput,
    OperationTimeout,
    
    // Backend errors
    BackendNotAvailable,
    BackendComputeFailed,
    BackendInvalidDataType,
    BackendInsufficientMemory,
    
    // Registry errors
    CapabilityNotFound,
    DuplicateCapability,
    InvalidCapability,
    
    // System errors
    InitializationFailed,
    InternalError,
};

/// Map YamoriError to human-readable strings
pub fn errorDescription(err: YamoriError) []const u8 {
    return switch (err) {
        .UnknownOperation => "Operation not found in capability registry",
        .OperationNotSupported => "Operation not supported by selected backend",
        .InvalidOperationInput => "Invalid input types or lengths for operation",
        .OperationTimeout => "Operation exceeded time limit",
        .BackendNotAvailable => "Requested backend is not available",
        .BackendComputeFailed => "Backend computation failed",
        .BackendInvalidDataType => "Backend does not support input data type",
        .BackendInsufficientMemory => "Backend ran out of memory",
        .CapabilityNotFound => "Capability not found in registry",
        .DuplicateCapability => "Capability already registered",
        .InvalidCapability => "Invalid capability definition",
        .InitializationFailed => "Failed to initialize Yamori",
        .InternalError => "Internal Yamori error",
    };
}
```

pub fn mapArrowError(arrow_err: ArrowError) YamoriError {
    return switch (arrow_err) {
        .FunctionNotFound => YamoriError.UnknownOperation,
        .InvalidDataType => YamoriError.BackendInvalidDataType,
        .InvalidInputLength => YamoriError.InvalidOperationInput,
        .ComputeFailed => YamoriError.BackendComputeFailed,
        .NullInput => YamoriError.InvalidOperationInput,

}

test "Dispatch error normalization converts Arrow errors to YamoriError" {
    var gpa = std.testing.allocator;
    var reg = CapabilityRegistry.init(gpa);
    defer reg.deinit();

    // Register a capability with Arrow backend
    const cap = Capability.init(
        gpa, "add", 1, "Arrow add",
        &.{Capability.TypeDescriptor{ .category = .vector, .element_type = .f64 }},
        .{},
        .arrow,
    ) catch |err| return err;
    defer cap.deinit(gpa);
    try reg.register(cap);

    // Simulate Arrow compute failure
    const arrow_err = ArrowError.ComputeFailed;
    const normalized_err = ArrowAdapter.mapArrowError(arrow_err);
    
    try std.testing.expectEqual(YamoriError.BackendComputeFailed, normalized_err);
}

test "Dispatch error normalization converts GSL errors to YamoriError" {
    const gsl_err = GSLAdapterError.MemoryAllocationFailed;
    const normalized_err = GSLAdapter.mapGSLAdapterError(gsl_err);
    
    try std.testing.expectEqual(YamoriError.BackendInsufficientMemory, normalized_err);
